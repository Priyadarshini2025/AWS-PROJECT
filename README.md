# AWS-PROJECT

## Project Overview
This repository contains a website project developed using frontend web technologies. It includes multiple webpages, styling, images, fonts, and JavaScript functionality.

## Objective
The objective of this project is to develop a structured and user-friendly website with multiple pages and an organized frontend design.

## Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Interactive functionality

## Project Features
- Multiple webpages
- Organized website navigation
- Responsive styling (if implemented and tested)
- Custom fonts and images
- JavaScript-based functionality

## Installation and Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/Priyadarshini2025/AWS-PROJECT.git
   ```

2. Open the project folder:
   ```bash
   cd AWS-PROJECT
   ```

3. Open `index.html` in your web browser.

No additional software installation is required to view the basic website.
